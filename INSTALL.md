# django-siteblocks installation

Python `pip` package is required to install `django-siteblocks`.

## From sources

Use the following command line to install `django-siteblocks` from sources directory (containing `pyproject.toml`):

```shell
pip install .
```

## From PyPI

Alternatively you can install `django-siteblocks` from PyPI:

```shell
pip install django-siteblocks
```

Use `-U` flag for upgrade:

```shell
pip install -U django-siteblocks
```
